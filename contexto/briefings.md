## Como funciona

```
Leo (território) → Caio (banco de briefings) → Hugo seleciona → Caio cria briefing.md → Pauta de produção
```

**Status de cada peça:**
- 🗂 **Backlog** — ideia registrada, briefing ainda não desenvolvido
- 📄 **Briefing criado** — arquivo `briefing.md` salvo, aguardando validação de Hugo
- ✏️ **Em Produção** — Julia escrevendo
- 👀 **Aguardando Revisão** — Ana revisando
- 🎨 **Design em Produção** — Bia produzindo
- ✅ **Aguardando Publicação** — visual aprovado, aguardando data de publicação
- 📅 **Agendado (DD/MM)** — data de publicação confirmada
- ✅ **Publicado (DD/MM)** — foi ao ar
- 🗃 **Arquivado** — descartado ou suspenso indefinidamente

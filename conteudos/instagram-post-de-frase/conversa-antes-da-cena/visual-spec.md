# Visual Spec — C-090

**Conceito visual:** Frase de impacto isolada, tom mais leve e convidativo, sem elementos gráficos adicionais, conforme Layout de Frase do design system.

**Tipo de Grid:** Conceitual / frase

**Fundo:** Carbon Black `#141419` — alterna com o Deep Plum do C-089 (post de frase anterior) e do C-091 (peça-irmã), mantendo o ciclo do feed variado entre os posts conceituais.

**Formato e dimensões:** Post único Instagram, 1080×1350px, template "Post Frase Efeito" (ID: `EAHMvTf7Hkk`).

**Estilo fotográfico/visual:** Layout de Frase — frase dominante, sem subtítulo, tipografia Playfair Display Bold, tamanho padrão 103pt.

**Paleta de cores:** Fundo Carbon Black, texto Warm Light (contraste obrigatório para fundo escuro).

**Elementos obrigatórios:** wordmark em versão clara (Warm Light) no canto inferior, sem linha vertical Scarlet.

**Referências visuais:** referência de composição vinda de imagem enviada pelo Hugo (conta @kyn.tv) — fundo escuro, tipografia serifada elegante, frase centralizada, marca discreta embaixo. Estrutura similar já usada no template padrão da SB.

**Observações para o Revisor:** Frase relativamente longa (12 palavras) — checar se cabe em 103pt sem quebra de palavra no meio; se necessário, reduzir levemente o tamanho da fonte mantendo hierarquia com o restante do grid.

# Visual Spec — C-079

**Conceito visual:** Tom mais sério e conceitual que o C-001 — o carrossel fala sobre reconhecer padrões perigosos, então o visual deve comunicar atenção e clareza, sem ilustrar literalmente "perigo" ou usar imagens de conflito.

**Tipo de Grid:** Educativo aprofundado

**Fundo:** Skin Nude `#e6cfc3` — mesma cor usada no carrossel anterior do território (C-057, publicado 27/06), mantendo consistência visual entre as duas peças que tratam do mesmo assunto.

**Formato e dimensões:** Carrossel Instagram, 1080×1350px por slide (8 slides), template "Post Carrossel Livre" (ID: `EAHM8m_nVF4`).

**Estilo fotográfico/visual:** Layout Editorial com linha vertical Scarlet nos slides de conteúdo — a linha Scarlet aqui reforça a leitura de "atenção", coerente com o tema. Respiro e Finalização mais limpos, sem linha vertical.

**Paleta de cores:** Base Skin Nude, texto Carbon Black, Scarlet Pulse pontual na linha vertical e em pequenos destaques nos slides que citam as frases-exemplo entre aspas.

**Elementos obrigatórios:** wordmark, linha vertical Scarlet nos slides de conteúdo, aspas visuais destacando as frases-exemplo ("só eu te entendo...", etc.) como elemento de design.

**Referências visuais:** nenhuma foto de pessoas é necessária — peça pode ser 100% tipográfica, como o C-057 já publicado.

**Palavras-chave para banco de imagens:** não aplicável — peça tipográfica.

**Observações para o Revisor:** conferir se as frases entre aspas (exemplos de fala) se destacam visualmente do texto de desenvolvimento, pra facilitar leitura rápida no feed.

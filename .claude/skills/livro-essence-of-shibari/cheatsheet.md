# Cheatsheet — Essence of Shibari

## Rope Material Decision

| Need | Use | Avoid |
|---|---|---|
| Standard kinbaku | Jute (6mm × 7.5–8m) | Manila, Sisal |
| Wet environments | Nylon | Jute/Hemp (absorbs water) |
| Comfort priority, light use | Cotton | Cotton under high tension (knots jam) |
| Larger body | 8mm jute | — |

---

## Tie Variant Selection

| Situation | Tie to Use |
|---|---|
| Single limb, general | SCT Square Knot |
| Single limb, beginner top | SCT Double Square Knot |
| Single limb, tight wraps needed | SCT Square Knot (NOT Carrick Bend) |
| Two limbs together | Double Column Tie |
| Mid-run anchor | Figure 8 Friction |
| Finishing | Double Half Hitch |

---

## Common Tie Selection by Intent

| Intent | Use |
|---|---|
| Erotic/interactive, lots of movement | Hands Behind Head — Crotch Rope |
| Restriction + longer duration | Hands Behind Head — Affixed Arm |
| Full-body aesthetic coverage | Tortoise Shell / Rhombus |
| Leg restriction (open) | Futomomo — Letter M |
| Leg restriction (compact) | Futomomo — Crab Tie |
| Suspension-ready base | Hip & Crotch — Akechi/Kanna style |
| Most iconic / photographed | TK (Takate Kote) |
| Intense domination position | Strappado (after Arm Binder) |

---

## Safety: Tie Here / Don't Tie Here

| Tie Here | Never Tie Here |
|---|---|
| Upper arm (thick muscle) | Inner wrist groove |
| Thigh (thick muscle) | Inside of elbow |
| Hip bones (for suspension) | Armpit (brachial plexus) |
| Rib area (over ribs) | Neck — either side (carotid) |
| Ankle (wide SCT, lower leg) | Neck — center (windpipe) |

---

## Nerve Warning Signs → Action

| Signal | Meaning | Action |
|---|---|---|
| Numbness | Nerve under compression | Stop. Release wraps. Assess. |
| Tingling | Early nerve compression | Stop. Adjust immediately. |
| Unusual skin color (blue/white) | Circulation restricted | Release. Do not re-tie same zone. |
| "Drop wrist" | Radial nerve injury (TK) | Stop immediately. Medical attention. |

---

## TK: Go / No-Go Checks

| Check | Pass | Fail → Action |
|---|---|---|
| Forearm gap | 2+ finger-widths | Release and reset |
| Bottom can exchange hand positions | Yes | Release and reset |
| Wraps order | 2nd below 1st | Remove upper wrap and redo |
| Tension even across chest | Yes | Adjust before securing |

---

## Equipment: Load-Bearing Rules

| Equipment | Safe for suspension | Notes |
|---|---|---|
| Certified carabiner (rated) | Yes | Verify load rating |
| Ornamental carabiner | No | Decoration only |
| Door frame | No | Cannot bear body weight |
| Clothes stand | No | Cannot bear body weight |
| Ceiling beam | Only if structurally rated | Verify with building knowledge |

## Session Flow Decisions

```
Before session:
  → New partner? → Run full pre-session assessment (5 steps)
  → D/s context? → Establish safe word before anything else
  → Suspension planned? → Inspect all hardware ratings now

Choosing a tie:
  → What is the intent? → Match intent to tie (table above)
  → Furniture involved? → Tie body first, then anchor to fixture

During session:
  → Numbness/tingling reported? → Stop. Release. Assess.
  → Bottom's flexibility reduced (cold)? → Reduce intensity, check temperature
  → Top needs to move bottom? → Move yourself around them, not them around you

Ending session:
  → Release from most restrictive first
  → Stay present — do not leave immediately after release
```
